# ANTIGRAVITY - メンズ脱毛アフィリエイトサイト

## プロジェクト概要
- **目的**: AGAサイトと同等レイヤーの信頼性・専門性を持つアフィリエイトサイトによる長期収益化。
- **ターゲット/利用シーン**: 20代後半以降で、モテたい・オシャレになりたいと一歩踏み出そうとしている男性。メンズ脱毛に興味はあるがまだ行動できていない層。
- **独自の強み**: 
  - 薬事承認機などの客観的データに基づく詳細な脱毛機の比較。
  - サロン・医療双方のメリット（安さ・効果など）とデメリットをフラットに比較。
  - ユーザーが求める「モテ」直結のメリット訴求と、「将来ヒゲを生やしたくなった場合」にも対応できる回数（減毛）提案。

## 技術スタック
- HTML5, CSS3, Vanilla JavaScript（AGAサイトをベースにした高速かつ軽量な静的サイト構成）
- レスポンシブ対応（スマートフォン優先）

## MVPの範囲（今回の改修方針）
1. **ファーストビュー&「モテ・清潔感」訴求**: ターゲットの悩みに寄り添い、脱毛で得られる最大のメリット（モテ要素、コスパ・タイパ）を強調。
2. **回数設計（デザイン脱毛）の明記**: 完全なツルツルだけでなく、減毛（薄くする）段階での効果や、将来生やしたくなった場合の選択肢を提示。
3. **脱毛機の詳細比較**: レーザーの種類（ヤグ、アレキ、ダイオード）や熱破壊式/蓄熱式、国の薬事承認機についての客観的データを詳細な表形式で提示。
4. **サロン vs 医療の明確化**: サロンの安さや痛みの少なさといったサロン側の強みも明記し、比較の公平性と信頼度を高める。
5. **信頼性の高いクリニック比較**: 脱毛機の種類や痛みの少なさなど、客観的データに裏打ちされた誠実なクリニック紹介。
